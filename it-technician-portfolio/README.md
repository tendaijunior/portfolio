# IT Technician Portfolio Lab

Practical support projects demonstrating troubleshooting, documentation, automation, security awareness, and operational discipline.

| Project | Hiring signal | Technologies |
| --- | --- | --- |
| [Support Snapshot](support-snapshot/README.md) | Endpoint diagnostics and escalation | PowerShell, Windows |
| [PatchPulse](patch-pulse/README.md) | Patch posture and risk auditing | PowerShell, CSV |
| [RestoreReady](restore-ready/README.md) | Backup integrity and recovery readiness | PowerShell, hashing, JSON |
| [CableMap](cable-map/README.md) | Network port documentation | Python, CSV, HTML |
| [Ticket Triage Lab](ticket-triage-lab/README.md) | Help-desk prioritization and SLA reasoning | Python, JSON |

## Working principles

1. Gather evidence before changing a system.
2. Protect user and business data.
3. Automate repeatable checks.
4. Produce clear handover documentation.
5. Verify outcomes and record limitations.

All examples use synthetic data. Never publish client credentials, production IP addresses, serial numbers, or confidential screenshots.
