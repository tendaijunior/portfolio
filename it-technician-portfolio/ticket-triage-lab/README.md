# Ticket Triage Lab

Scores synthetic help-desk tickets using business impact, urgency, security indicators, and affected-user count. It demonstrates that priority should be explainable rather than based on who complains most loudly.

## Demonstrates

- Incident prioritization and SLA awareness
- Security escalation
- Transparent decision-making
- Python and JSON fundamentals

## Usage

```powershell
python .\triage.py .\sample-tickets.json
```

This is a training model, not a replacement for an organization's approved incident policy.
